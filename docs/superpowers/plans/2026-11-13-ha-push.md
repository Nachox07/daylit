# Push Updates From Home Assistant (Experimental) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** With the new opt-in key `homeAssistant.push`, both apps keep a WebSocket open to Home Assistant, subscribed (`subscribe_entities`) to exactly the entities the tick reads. A change asks for the existing tick within about 1 s (the daylight sensor alone at most once a minute), and polling drops to 300 s while the socket is healthy. With the key off, nothing changes.

**Architecture:** The pure parts live in `mac/Sources/DaylitCore/Push.swift` and its twin `windows/Push.cs`: the socket URL, the entity list, message parsing (`auth_required`, `auth_ok`, `auth_invalid`, `result`, `event` with `a`/`c`/`r`, `pong`), the outgoing messages, the tick decision, the one pending tick (`PushTimer`), the backoff, the poll interval, the open/closed rule and the log lines. Each app gets a `PushClient` (macOS `URLSessionWebSocketTask`, Windows `ClientWebSocket` with its own receive loop that hands each message to the UI thread). The controller only tells the client what to connect to (`update(target)` / `Update(target)`), reads `healthy` for the poll interval, and shows `problem` after a rejected token. The socket never carries data into the tick: the tick still reads everything through the REST template.

**Tech Stack:** Swift 5.9 package (XCTest, Foundation `URLSessionWebSocketTask`, `Network.NWPathMonitor`), .NET 10 WPF (xUnit, `System.Net.WebSockets.ClientWebSocket`, `NetworkChange`), Home Assistant WebSocket API.

**Spec:** `docs/superpowers/specs/2026-11-13-ha-push-design.md` (read it once before Task 1).

## What Home Assistant sends (checked against its source)

Checked on 2026-11-12 against `home-assistant/core` branch `dev` at `c62392a36f50956001d5b839815055d84fd1a606`, and the developer docs page (`developers.home-assistant.io/docs/api/websocket`, now redirecting to `contributors.home-assistant.io/core/internals/websocket-api/`):

- **Auth** (`homeassistant/components/websocket_api/auth.py`): the server sends `{"type":"auth_required","ha_version":…}`; the client answers `{"type":"auth","access_token":"…"}`; then `{"type":"auth_ok","ha_version":…}` or `{"type":"auth_invalid","message":"Invalid access token or password"}` and the server disconnects.
- **Commands** carry an increasing `id`; replies copy it. Success: `{"id":N,"type":"result","success":true,"result":null}` (`messages.py` `result_message`); failure has `"success":false` and an `error` object.
- **Ping:** `{"id":N,"type":"ping"}` → `{"id":N,"type":"pong"}` (`commands.py` `handle_ping`, `messages.py` `pong_message`). Separately, the server's aiohttp socket sends protocol-level pings every 55 s (`http.py`, `heartbeat=55`); both client libraries answer those by themselves.
- **`subscribe_entities`** (`commands.py` `handle_subscribe_entities`): optional `entity_ids` list. The server sends the `result` first, then one event with **every** matching state under `a`: `{"id":N,"type":"event","event":{"a":{"<entity_id>":{"s":…,"a":{…},"c":…,"lc":…}}}}` (`_send_handle_entities_init_response`; compressed state keys `s`, `a`, `c`, `lc`, `lu` from `core.py` `as_compressed_state` and `const.py`).
- **Later events** (`messages.py` `_state_diff_event`): a removed entity → `{"r":["<entity_id>"]}`; a new one → `{"a":{…}}`; a change → `{"c":{"<entity_id>":{"+":{…},"-":{"a":[…]}}}}`. A `c` event is sent for **every** `state_changed`, including attribute-only updates (the sun's elevation, a light's brightness).
- **Coalescing:** the server sends JSON lists only after the client opts in with `supported_features` / `coalesce_messages`. Daylit never does, so every frame is one object; a list parses as `other`.

## Decisions this plan takes (the spec left them open)

1. **Entity list** = the HA-wide entities plus the helpers of **every configured monitor** in `config.monitors`, connected or not, once each, sorted. It does not change when a monitor is plugged in, so no resubscribe on display changes; a change to an unplugged monitor's helper costs one harmless tick. The sun is `sun.sun` when unset or not an entity id, as the template does. A monitor's `sensor` is **never** subscribed: Daylit publishes it every tick, so following it would loop.
2. **Daylight limit** is measured from the **last tick of any kind** (`lastTick`), not a separate "last daylight tick": every tick reads the sensor. A daylight-only change ticks at once when the last tick is 60 s old, else at `lastTick + 60`. Unknown entities next to it do not change that; a mix with any known entity ticks at once; with no `homeAssistant.light` every relevant change ticks at once.
3. **Debounce** is a fixed 1 s window from the first change, not reset by later ones, so a steady stream cannot starve the tick. A change while a daylight tick is waiting brings it forward (`PushTimer`).
4. **The initial `a` snapshot** after each (re)connect asks for one catch-up tick: changes made while disconnected are picked up at once.
5. **Healthy** = `auth_ok` and a successful `result` for the subscribe id. While healthy the poll interval is `max(300, today's interval)`, so a longer configured `timing` value is kept.
6. **"An auth failure"** in the spec's reconnect list is read as any failure before `auth_ok` other than `auth_invalid`. Only `auth_invalid` stops retrying. **No token stored** also stops, quietly (`push: no token stored, waiting for one`): the REST tick already shows the token problem, and polling the keychain every minute would cost battery.
7. **Backoff and the log rule reset** only once a connection has lasted one ping/pong cycle (~70 s), so a server that accepts and then drops cannot loop every 2 s. Wake and network changes reconnect at once with the backoff reset.
8. **Pong timeout** is 10 s after each 60 s ping.
9. **One more closed condition:** no external monitor connected (polling stops then too).
10. **"Until the token or config changes":** config = any reload (`force` reconnect, which also resubscribes) or a different target; token = saving one in the app's token dialog (Mac `TokenWindow`, Windows `AskToken`). A token stored from Terminal is picked up at the next reload or start.
11. **Problem line precedence:** a REST error shown this tick wins; the push problem shows when REST is fine (Mac `configProblem ?? push.problem`; Windows `Error ??= push?.Problem` after the REST block).
12. **Log lines:** `push: lost (<reason>)` follows `HAErrorRule.shouldLog` keyed by the reason; `push: connected (N entities)` on every successful subscribe; `push: off` only when it was on; event details only in the debug log (`DAYLIT_DEBUG=1`, Mac). Reasons are fixed words or an error's domain and code (Mac `NSPOSIXErrorDomain 57`, Windows `WebSocket ConnectionClosedPrematurely`), never an error message that could quote a request.
13. **Network change:** Mac `NWPathMonitor` (status plus interface names; its first report is the current network and is ignored). Windows `NetworkChange.NetworkAddressChanged`, which fires several times per change, debounced to one reconnect 2 s after the last. **Wake:** Mac in the existing `didWake` observer after its 3 s wait; Windows on `PowerModes.Resume`. No sleep hook: the wake reconnect replaces a socket that died during sleep.
14. **`--check-config`** reports `"push": true|false` in its `homeAssistant` block, and a note when push is on but the source is not Home Assistant.
15. **Docs:** `docs/setup.md` gets an *Experimental* section and a note in the Tuning table; README → *How it works* gets one clause (CONTRIBUTING asks behaviour changes to start there); `AGENTS.md` one line; `config.example.json` shows `"push": false`.
16. **The sun** ticks at once, as the spec lists it. Home Assistant updates `sun.sun`'s elevation every few minutes, each one a `c` event: at most a tick per update, well under the 30 s poll it replaces. The owner's battery measurement covers it.

// Push updates from Home Assistant (experimental, config homeAssistant.push): the WebSocket only says
// *when* to tick. The tick still reads everything through the REST template. The app side is
// mac/Sources/Daylit/PushClient.swift; windows/Push.cs is the twin of this file.
import Foundation

public enum PushRule {
    /// `ws(s)://<host>/api/websocket` from homeAssistant.url, or nil when it is not an http(s) URL.
    public static func socketURL(_ http: String) -> URL? {
        guard var c = URLComponents(string: http.trimmingCharacters(in: .whitespaces)), c.host?.isEmpty == false else { return nil }
        switch c.scheme?.lowercased() {
        case "http": c.scheme = "ws"
        case "https": c.scheme = "wss"
        default: return nil
        }
        var path = c.path
        while path.hasSuffix("/") { path.removeLast() }
        c.path = path + "/api/websocket"
        c.query = nil; c.fragment = nil; c.user = nil; c.password = nil
        return c.url
    }

    /// Every entity the tick reads, once each, sorted: the HA-wide ones (the sun is sun.sun when unset or not
    /// an entity id, as in the template) and each configured monitor's helpers. Never a monitor's `sensor`:
    /// Daylit publishes it, so following it would make every publish trigger another tick.
    public static func entities(_ c: Config) -> [String] {
        guard let ha = c.homeAssistant else { return [] }
        let sun = ha.sun.flatMap { Config.isEntityId($0) ? $0 : nil } ?? "sun.sun"
        var ids: [String?] = [ha.autoSwitch, sun, ha.cover, ha.lights, ha.light]
        for m in c.monitors ?? [] {
            guard let h = m.homeAssistant else { continue }
            ids += [h.day, h.blindDown, h.night, h.nightLights, h.set]
        }
        return Array(Set(ids.compactMap { $0 }.filter { !$0.isEmpty && Config.isEntityId($0) })).sorted()
    }
}
```

/// One message from Home Assistant's WebSocket API, reduced to what Daylit needs.
public enum PushMessage: Equatable {
    case authRequired
    case authOk
    case authInvalid(String)
    case result(id: Int, ok: Bool)
    /// A subscribe_entities event: the entity ids it added (`a`), changed (`c`) or removed (`r`).
    case event(Set<String>)
    case pong
    case other
}

extension PushRule {
    /// One incoming text frame. Anything unexpected (bad JSON, a list, an unknown type) is `.other`.
    public static func parse(_ text: String) -> PushMessage {
        guard let d = text.data(using: .utf8), let o = (try? JSONSerialization.jsonObject(with: d)) as? [String: Any],
              let type = o["type"] as? String else { return .other }
        switch type {
        case "auth_required": return .authRequired
        case "auth_ok": return .authOk
        case "auth_invalid": return .authInvalid(o["message"] as? String ?? "")
        case "pong": return .pong
        case "result":
            guard let id = o["id"] as? Int, let ok = o["success"] as? Bool else { return .other }
            return .result(id: id, ok: ok)
        case "event":
            guard let e = o["event"] as? [String: Any] else { return .other }
            var ids = Set<String>()
            if let a = e["a"] as? [String: Any] { ids.formUnion(a.keys) }
            if let c = e["c"] as? [String: Any] { ids.formUnion(c.keys) }
            if let r = e["r"] as? [String] { ids.formUnion(r) }
            return .event(ids)
        default: return .other
        }
    }

    /// The answer to auth_required. The token goes only here: never into a URL, a log line or an error.
    public static func authMessage(token: String) -> String {
        json(["type": "auth", "access_token": token])
    }
    public static func subscribeMessage(id: Int, entities: [String]) -> String {
        json(["id": id, "type": "subscribe_entities", "entity_ids": entities])
    }
    public static func pingMessage(id: Int) -> String { json(["id": id, "type": "ping"]) }

    static func json(_ o: [String: Any]) -> String {
        guard let d = try? JSONSerialization.data(withJSONObject: o, options: [.sortedKeys]) else { return "{}" }
        return String(decoding: d, as: UTF8.self)
    }

    /// The log lines (Log.write adds the time). None of them can carry the token.
    public static func connectedLine(_ count: Int) -> String { "push: connected (\(count) entities)" }
    public static func lostLine(_ reason: String, retryIn: Double) -> String { "push: lost (\(reason)), retrying in \(Int(retryIn))s" }
    public static func rejectedLine(_ reason: String) -> String { "push: token rejected (\(reason)), not retrying until the token or config changes" }
    public static let offLine = "push: off"
    /// The problem line shown in the panel after auth_invalid, like the REST token errors.
    public static let rejectedProblem = "Home Assistant rejected the token (push updates)"
}

/// What a set of changed entities asks for.
public enum PushTick: Equatable {
    case now                 // a tick after the 1 s debounce
    case after(Double)       // the daylight sensor alone: a tick in this many seconds
    case ignore
}

extension PushRule {
    /// A burst of changes within this many seconds runs one tick.
    public static let debounce: Double = 1
    /// The daylight sensor alone ticks at most this often (it can report every few seconds).
    public static let daylightEvery: Double = 60
    /// While the socket is connected and subscribed, polling is only the safety net.
    public static let healthyPollSeconds: Double = 300
    /// An application ping this often; no pong within `pongTimeout` means the connection is gone.
    public static let pingEvery: Double = 60
    public static let pongTimeout: Double = 10
    /// Waits before each reconnect attempt; the last one repeats.
    public static let backoff: [Double] = [2, 5, 15, 60]

    /// Whether these changes need a tick. `daylight` is homeAssistant.light; `lastTick` is when the last tick
    /// ran (Unix seconds; any tick reads the daylight sensor too).
    public static func decide(changed: Set<String>, subscribed: Set<String>, daylight: String?, lastTick: Double?, now: Double) -> PushTick {
        let relevant = changed.intersection(subscribed)
        if relevant.isEmpty { return .ignore }
        if let d = daylight, relevant == [d] {
            guard let last = lastTick else { return .now }
            let wait = daylightEvery - (now - last)
            return wait <= 0 ? .now : .after(wait)
        }
        return .now
    }

    /// The wait before reconnect attempt `attempt` (0 = the first after a drop).
    public static func retryDelay(attempt: Int) -> Double { backoff[min(max(attempt, 0), backoff.count - 1)] }

    /// The poll interval: today's while the socket is not healthy, else 300 s (or the configured one when longer).
    public static func pollInterval(healthy: Bool, onBattery: Bool, tuning: Tuning) -> Double {
        let normal = onBattery ? tuning.batteryPollSeconds : tuning.pollSeconds
        return healthy ? max(healthyPollSeconds, normal) : normal
    }

    /// Whether the socket should be open: push on, Home Assistant the source, Automatic on, not paused on
    /// battery, and a monitor to drive.
    public static func wanted(push: Bool?, source: Source, paused: Bool, auto: Bool, hasMonitors: Bool) -> Bool {
        push == true && source == .homeAssistant && !paused && auto && hasMonitors
    }
}

/// The one pending push tick. A change asks for a tick in 1 s; more changes before it fires join it,
/// so a burst runs one tick. A daylight-only change waits for its limit, unless a tick is already due.
public struct PushTimer: Equatable {
    public private(set) var due: Double?
    public init() {}
    /// Adds a request; true when `due` moved, so the caller reschedules its timer.
    public mutating func add(_ t: PushTick, now: Double) -> Bool {
        let at: Double
        switch t {
        case .ignore: return false
        case .now: at = now + PushRule.debounce
        case .after(let s): at = now + max(s, PushRule.debounce)
        }
        if let d = due, d <= at { return false }
        due = at
        return true
    }
    /// The timer fired (or the socket closed): nothing pending.
    public mutating func clear() { due = nil }
}

The app target has no tests; Task 8 runs this file against a fake server. How it works:

- `update(target, force:)` is the only way in from the model. The same target keeps the connection; `nil` closes it and logs `push: off` once.
- `open()` reads the token off the main thread (`HAClient.token` runs `/usr/bin/security`), then starts the socket and the receive loop. The token lives only in that loop's local variable until `auth_required`, then is dropped.
- `conn` is bumped on every open and close, so a callback from an older connection does nothing.
- `lost(reason)` closes, logs by `HAErrorRule.shouldLog`, and retries after `PushRule.retryDelay(attempt:)`.
- `rejected(why)` (auth_invalid) closes, stops, sets `problem` and asks for a tick so the problem line shows.

```swift
// Push updates from Home Assistant (experimental, config homeAssistant.push). A WebSocket subscribed to the
// entities the tick reads; a change only asks for a tick (DaylitCore.PushRule decides when). The token is
// read from the keychain, sent once in the auth message, and never logged or put in a URL.
import Foundation
import Network
import DaylitCore

@MainActor final class PushClient {
    /// What to connect to. The same target keeps the connection.
    struct Target: Equatable {
        let url: URL
        let tokenName: String
        let entities: [String]
        let daylight: String?
    }

    /// Connected and subscribed: polling can slow down to PushRule.healthyPollSeconds.
    private(set) var healthy = false
    /// After auth_invalid: the problem line for the panel, until the token or the config changes.
    private(set) var problem: String?

    private let tick: () -> Void
    private let lastTick: () -> Date
    private var target: Target?
    private var task: URLSessionWebSocketTask?
    /// Bumped on every open and close, so callbacks from an older connection do nothing.
    private var conn = 0
    private var attempt = 0
    /// auth_invalid or no token: no retry until the token or the config changes.
    private var stopped = false
    private var nextId = 1, subscribeId = 0
    private var awaitingPong = false
    private var retryTask: Task<Void, Never>?, pingTask: Task<Void, Never>?, tickTask: Task<Void, Never>?
    private var timer = PushTimer()
    /// The once-then-every-10-minutes rule (HAErrorRule.shouldLog) for "lost" lines.
    private var lastReason: String?, loggedAt: Date?
    private let session = URLSession(configuration: .ephemeral)
    private var path: NWPathMonitor?
    private var lastPath: String?

    init(tick: @escaping () -> Void, lastTick: @escaping () -> Date) {
        self.tick = tick
        self.lastTick = lastTick
    }

    /// Opens, keeps or closes the socket. `force` reconnects even when nothing changed (a config reload resubscribes).
    func update(_ t: Target?, force: Bool = false) {
        if t == target && !force { return }
        let was = target
        target = t
        stopped = false; problem = nil   // a new config gets a fresh try
        close()
        attempt = 0; lastReason = nil; loggedAt = nil
        guard t != nil else {
            if was != nil { Log.write(PushRule.offLine) }
            return
        }
        watchNetwork()
        open()
    }

    /// A new token was saved: try again, also after auth_invalid.
    func tokenChanged() {
        guard target != nil else { return }
        stopped = false; problem = nil
        close(); attempt = 0
        open()
    }

    /// Wake from sleep or a network change: the old connection may be dead without knowing it.
    func reconnect(_ why: String) {
        guard target != nil, !stopped else { return }
        log("push: reconnecting (\(why))")
        close(); attempt = 0
        open()
    }

    private func open() {
        guard let t = target, !stopped else { return }
        conn += 1
        let c = conn, name = t.tokenName
        Task {
            let token = await Task.detached { HAClient.token(name) }.value   // runs /usr/bin/security: off the main thread
            guard c == self.conn else { return }
            guard let token else {
                // The REST tick already shows "No Home Assistant token"; the token window calls tokenChanged().
                self.close(); self.stopped = true
                Log.write("push: no token stored, waiting for one")
                return
            }
            let ws = self.session.webSocketTask(with: t.url)
            self.task = ws
            ws.resume()
            self.receive(ws, c, token, t)
        }
    }

    private func receive(_ ws: URLSessionWebSocketTask, _ c: Int, _ token: String, _ t: Target) {
        Task {
            var token: String? = token   // sent once, then dropped
            while c == self.conn {
                let message: URLSessionWebSocketTask.Message
                do { message = try await ws.receive() } catch {
                    // A close frame from Home Assistant (a restart) reads better than the socket error it causes.
                    self.lost(ws.closeCode != .invalid ? "closed by Home Assistant" : Self.reason(error), c)
                    return
                }
                guard c == self.conn else { return }
                guard case .string(let text) = message else { continue }
                switch PushRule.parse(text) {
                case .authRequired:
                    guard let tk = token else { continue }
                    token = nil
                    self.send(ws, PushRule.authMessage(token: tk), c)
                case .authOk:
                    self.subscribeId = self.nextId; self.nextId += 1
                    self.send(ws, PushRule.subscribeMessage(id: self.subscribeId, entities: t.entities), c)
                case .authInvalid(let why):
                    self.rejected(why)
                    return
                case .result(let id, let ok) where id == self.subscribeId:
                    guard ok else { self.lost("subscribe refused", c); return }
                    self.healthy = true
                    Log.write(PushRule.connectedLine(t.entities.count))
                    self.startPing(ws, c)
                case .event(let ids):
                    self.request(ids, t)
                case .pong:
                    self.awaitingPong = false
                default:
                    break
                }
            }
        }
    }

    private func send(_ ws: URLSessionWebSocketTask, _ text: String, _ c: Int) {
        Task {
            do { try await ws.send(.string(text)) } catch { self.lost(Self.reason(error), c) }
        }
    }

    /// A ping every minute; no pong within 10 s closes and retries. A connection that lasted a minute ends
    /// the outage: the backoff and the log rule start again.
    private func startPing(_ ws: URLSessionWebSocketTask, _ c: Int) {
        pingTask?.cancel()
        pingTask = Task {
            while c == self.conn {
                try? await Task.sleep(nanoseconds: UInt64(PushRule.pingEvery * 1_000_000_000))
                guard c == self.conn, !Task.isCancelled else { return }
                self.awaitingPong = true
                let id = self.nextId; self.nextId += 1
                self.send(ws, PushRule.pingMessage(id: id), c)
                try? await Task.sleep(nanoseconds: UInt64(PushRule.pongTimeout * 1_000_000_000))
                guard c == self.conn, !Task.isCancelled else { return }
                if self.awaitingPong { self.lost("no pong", c); return }
                self.attempt = 0; self.lastReason = nil; self.loggedAt = nil
            }
        }
    }

    private func request(_ ids: Set<String>, _ t: Target) {
        let now = Date().timeIntervalSince1970
        let d = PushRule.decide(changed: ids, subscribed: Set(t.entities), daylight: t.daylight,
                                lastTick: lastTick().timeIntervalSince1970, now: now)
        guard timer.add(d, now: now), let due = timer.due else { return }
        log("push: \(ids.sorted().joined(separator: ", ")) changed, tick in \(Int((due - now).rounded())) s")
        tickTask?.cancel()
        let c = conn
        tickTask = Task {
            try? await Task.sleep(nanoseconds: UInt64(max(0, due - now) * 1_000_000_000))
            guard c == self.conn, !Task.isCancelled else { return }
            self.timer.clear()
            self.tick()
        }
    }

    private func lost(_ reason: String, _ c: Int) {
        guard c == conn, target != nil else { return }
        close()
        let delay = PushRule.retryDelay(attempt: attempt)
        attempt += 1
        let now = Date()
        if HAErrorRule.shouldLog(message: reason, lastMessage: lastReason, lastLogged: loggedAt?.timeIntervalSince1970,
                                 now: now.timeIntervalSince1970) {
            Log.write(PushRule.lostLine(reason, retryIn: delay))
            loggedAt = now
        }
        lastReason = reason
        let cc = conn
        retryTask = Task {
            try? await Task.sleep(nanoseconds: UInt64(delay * 1_000_000_000))
            guard cc == self.conn, !Task.isCancelled else { return }
            self.open()
        }
    }

    private func rejected(_ why: String) {
        close()
        stopped = true
        problem = PushRule.rejectedProblem
        Log.write(PushRule.rejectedLine(why))
        tick()   // shows the problem line
    }

    private func close() {
        conn += 1
        healthy = false; awaitingPong = false
        task?.cancel(with: .goingAway, reason: nil); task = nil
        retryTask?.cancel(); pingTask?.cancel(); tickTask?.cancel()
        retryTask = nil; pingTask = nil; tickTask = nil
        timer.clear()
    }

    /// Network changes (Wi-Fi to Ethernet, a VPN, another network): reconnect at once rather than wait for a missed pong.
    private func watchNetwork() {
        guard path == nil else { return }
        let m = NWPathMonitor()
        m.pathUpdateHandler = { [weak self] p in
            let key = "\(p.status) " + p.availableInterfaces.map(\.name).joined(separator: ",")
            Task { @MainActor in self?.pathChanged(key) }
        }
        m.start(queue: .main)
        path = m
    }

    private func pathChanged(_ key: String) {

# A fake Home Assistant WebSocket for the push client: auth, subscribe_entities, events, ping/pong.
import asyncio, json, sys, websockets
port, mode = int(sys.argv[1]), sys.argv[2]
async def handler(ws):
    print("SERVER path", ws.request.path, flush=True)
    await ws.send(json.dumps({"type": "auth_required", "ha_version": "2026.11.0"}))
    auth = json.loads(await ws.recv())
    print("SERVER auth keys", sorted(auth), "token ok", auth.get("access_token") == "fake-test-token", flush=True)
    if mode == "invalid":

    await ws.send(json.dumps({"type": "auth_ok", "ha_version": "2026.11.0"}))
    async def events(sid):
        await ws.send(json.dumps({"id": sid, "type": "event", "event": {"a": {"light.room": {"s": "on", "a": {}, "c": "x", "lc": 1}, "sun.sun": {"s": "above_horizon", "a": {"elevation": 20}, "c": "y", "lc": 1}}}}))
        await asyncio.sleep(3)

            await ws.send(json.dumps({"id": sid, "type": "event", "event": {"c": {"light.room": {"+": {"s": "off", "lc": 2}}}}})); await asyncio.sleep(0.2)
        await asyncio.sleep(3)
        await ws.send(json.dumps({"id": sid, "type": "event", "event": {"c": {"sensor.solar": {"+": {"s": "1200", "lu": 3}}}}}))
        await ws.send(json.dumps({"id": sid, "type": "event", "event": {"c": {"light.kitchen": {"+": {"s": "on"}}}}}))
        if mode == "drop":
            await asyncio.sleep(2); print("SERVER closing", flush=True); await ws.close()
    async for raw in ws:
        m = json.loads(raw); print("SERVER got", m.get("type"), m.get("entity_ids", ""), flush=True)
        if m["type"] == "subscribe_entities":
            await ws.send(json.dumps({"id": m["id"], "type": "result", "success": True, "result": None}))
            asyncio.create_task(events(m["id"]))
        elif m["type"] == "ping" and mode != "nopong":
            await ws.send(json.dumps({"id": m["id"], "type": "pong"}))
async def main():
    async with websockets.serve(handler, "127.0.0.1", port):
        await asyncio.sleep(float(sys.argv[3]))
asyncio.run(main())

// Push updates from Home Assistant (experimental, config homeAssistant.push): the WebSocket only says *when*
// to tick; the tick still reads everything through the REST template. Twin of mac/Sources/DaylitCore/Push.swift.
// No WPF or Win32 here: the test project compiles this file. The socket itself is PushClient.cs.
using System.Text.Json;

namespace Daylit;

enum PushKind { AuthRequired, AuthOk, AuthInvalid, Result, Event, Pong, Other }

/// One message from Home Assistant's WebSocket API, reduced to what Daylit needs. `Ids`: for an event, the entity
/// ids it added (`a`), changed (`c`) or removed (`r`).
sealed record PushMessage(PushKind Kind, string? Reason = null, int Id = 0, bool Ok = false, IReadOnlySet<string>? Ids = null) {
    public static readonly PushMessage Other = new(PushKind.Other);
}

enum PushTickKind { Now, After, Ignore }

/// What a set of changed entities asks for: a tick after the 1 s debounce, one in `Seconds`, or nothing.
readonly record struct PushTick(PushTickKind Kind, double Seconds = 0) {
    public static readonly PushTick Now = new(PushTickKind.Now);
    public static readonly PushTick Ignore = new(PushTickKind.Ignore);
    public static PushTick After(double seconds) => new(PushTickKind.After, seconds);
}

static class PushRule {
    /// A burst of changes within this many seconds runs one tick.
    public const double Debounce = 1;
    /// The daylight sensor alone ticks at most this often (it can report every few seconds).
    public const double DaylightEvery = 60;
    /// While the socket is connected and subscribed, polling is only the safety net.
    public const double HealthyPollSeconds = 300;
    /// An application ping this often; no pong within PongTimeout means the connection is gone.
    public const double PingEvery = 60, PongTimeout = 10;
    /// Waits before each reconnect attempt; the last one repeats.
    public static readonly double[] Backoff = [2, 5, 15, 60];

    /// `ws(s)://<host>/api/websocket` from homeAssistant.url, or null when it is not an http(s) URL.
    public static Uri? SocketUrl(string? http) {
        if (!Uri.TryCreate(http?.Trim(), UriKind.Absolute, out var u) || string.IsNullOrEmpty(u.Host)) return null;
        string? scheme = u.Scheme switch { "http" => "ws", "https" => "wss", _ => null };   // Uri lower-cases the scheme
        if (scheme == null) return null;
        return new UriBuilder(u) {
            Scheme = scheme, Port = u.IsDefaultPort ? -1 : u.Port, Path = u.AbsolutePath.TrimEnd('/') + "/api/websocket",
            Query = "", Fragment = "", UserName = "", Password = "",
        }.Uri;
    }

    /// Every entity the tick reads, once each, sorted: the HA-wide ones (the sun is sun.sun when unset or not an
    /// entity id, as in the template) and each configured monitor's helpers. Never a monitor's `sensor`: Daylit
    /// publishes it, so following it would make every publish trigger another tick.
    public static string[] Entities(Config c) {
        if (c.HomeAssistant is not { } ha) return [];
        string sun = ha.Sun is { } s && Config.IsEntityId(s) ? s : "sun.sun";
        var ids = new List<string?> { ha.AutoSwitch, sun, ha.Cover, ha.Lights, ha.Light };
        foreach (var m in c.Monitors ?? [])
            if (m?.HomeAssistant is { } h) ids.AddRange([h.Day, h.BlindDown, h.Night, h.NightLights, h.Set]);
        return ids.OfType<string>().Where(i => i.Length > 0 && Config.IsEntityId(i)).Distinct().OrderBy(i => i, StringComparer.Ordinal).ToArray();
    }

    /// One incoming text frame. Anything unexpected (bad JSON, a list, an unknown type) is Other.
    public static PushMessage Parse(string text) {
        try {
            using var doc = JsonDocument.Parse(text);
            var o = doc.RootElement;
            if (o.ValueKind != JsonValueKind.Object || !o.TryGetProperty("type", out var type) || type.ValueKind != JsonValueKind.String)
                return PushMessage.Other;
            switch (type.GetString()) {
                case "auth_required": return new(PushKind.AuthRequired);
                case "auth_ok": return new(PushKind.AuthOk);
                case "auth_invalid":
                    return new(PushKind.AuthInvalid, Reason: o.TryGetProperty("message", out var why) && why.ValueKind == JsonValueKind.String ? why.GetString() : "");
                case "pong": return new(PushKind.Pong);
                case "result":
                    if (o.TryGetProperty("id", out var idEl) && idEl.ValueKind == JsonValueKind.Number && idEl.TryGetInt32(out var idNum)
                        && o.TryGetProperty("success", out var okEl) && (okEl.ValueKind is JsonValueKind.True or JsonValueKind.False))
                        return new(PushKind.Result, Id: idNum, Ok: okEl.GetBoolean());
                    return PushMessage.Other;
                case "event":
                    if (!o.TryGetProperty("event", out var ev) || ev.ValueKind != JsonValueKind.Object) return PushMessage.Other;
                    var ids = new HashSet<string>();
                    if (ev.TryGetProperty("a", out var added) && added.ValueKind == JsonValueKind.Object)
                        foreach (var p in added.EnumerateObject()) ids.Add(p.Name);
                    if (ev.TryGetProperty("c", out var changed) && changed.ValueKind == JsonValueKind.Object)
                        foreach (var p in changed.EnumerateObject()) ids.Add(p.Name);
                    if (ev.TryGetProperty("r", out var removed) && removed.ValueKind == JsonValueKind.Array)
                        foreach (var x in removed.EnumerateArray()) if (x.ValueKind == JsonValueKind.String) ids.Add(x.GetString()!);
                    return new(PushKind.Event, Ids: ids);
                default: return PushMessage.Other;
            }
        } catch (JsonException) { return PushMessage.Other; }
    }

    /// The answer to auth_required. The token goes only here: never into a URL, a log line or an error.
    public static string AuthMessage(string token) => JsonSerializer.Serialize(new { type = "auth", access_token = token });
    public static string SubscribeMessage(int id, IReadOnlyList<string> entities) =>
        JsonSerializer.Serialize(new { id, type = "subscribe_entities", entity_ids = entities });
    public static string PingMessage(int id) => JsonSerializer.Serialize(new { id, type = "ping" });

    /// Whether these changes need a tick. `daylight` is homeAssistant.light; `lastTick` is when the last tick ran
    /// (Unix seconds; any tick reads the daylight sensor too).
    public static PushTick Decide(IEnumerable<string> changed, IReadOnlySet<string> subscribed, string? daylight, double? lastTick, double now) {
        var relevant = changed.Where(subscribed.Contains).ToHashSet();
        if (relevant.Count == 0) return PushTick.Ignore;
        if (daylight != null && relevant.Count == 1 && relevant.Contains(daylight)) {
            if (lastTick is not double last) return PushTick.Now;
            double wait = DaylightEvery - (now - last);
            return wait <= 0 ? PushTick.Now : PushTick.After(wait);
        }
        return PushTick.Now;
    }

    /// The wait before reconnect attempt `attempt` (0 = the first after a drop).
    public static double RetryDelay(int attempt) => Backoff[Math.Clamp(attempt, 0, Backoff.Length - 1)];

    /// The poll interval: today's while the socket is not healthy, else 300 s (or the configured one when longer).
    public static double PollInterval(bool healthy, bool onBattery, Tuning t) {
        double normal = onBattery ? t.BatteryPollSeconds : t.PollSeconds;
        return healthy ? Math.Max(HealthyPollSeconds, normal) : normal;
    }

    /// Whether the socket should be open: push on, Home Assistant the source, Automatic on, not paused on battery,
    /// and a monitor to drive.
    public static bool Wanted(bool? push, Source source, bool paused, bool auto, bool hasMonitors) =>
        push == true && source == Source.HomeAssistant && !paused && auto && hasMonitors;

    /// The log lines (Log.Write adds the time). None of them can carry the token.
    public static string ConnectedLine(int count) => $"push: connected ({count} entities)";
    public static string LostLine(string reason, double retryIn) => $"push: lost ({reason}), retrying in {(int)retryIn}s";
    public static string RejectedLine(string reason) => $"push: token rejected ({reason}), not retrying until the token or config changes";
    public const string OffLine = "push: off";
    /// The problem line shown in the panel after auth_invalid, like the REST token errors.
    public const string RejectedProblem = "Home Assistant rejected the token (push updates)";
}

/// The one pending push tick. A change asks for a tick in 1 s; more changes before it fires join it, so a burst
/// runs one tick. A daylight-only change waits for its limit, unless a tick is already due.
sealed class PushTimer {
    public double? Due { get; private set; }
    /// Adds a request; true when Due moved, so the caller restarts its timer.
    public bool Add(PushTick t, double now) {
        double at;
        switch (t.Kind) {
            case PushTickKind.Ignore: return false;
            case PushTickKind.Now: at = now + PushRule.Debounce; break;
            default: at = now + Math.Max(t.Seconds, PushRule.Debounce); break;
        }
        if (Due is double due && due <= at) return false;
        Due = at;
        return true;
    }
    /// The timer fired (or the socket closed): nothing pending.
    public void Clear() => Due = null;
}

```csharp
// Push updates from Home Assistant (experimental, config homeAssistant.push). A WebSocket subscribed to the
// entities the tick reads; a change only asks for a tick (PushRule in Push.cs decides when). The receive loop runs
// on the thread pool and hands each message to the UI thread; everything else here runs on the UI thread. The token
// is sent once in the auth message and never logged or put in a URL. Twin of mac/Sources/Daylit/PushClient.swift.
using System.IO;
using System.Net.WebSockets;
using System.Text;
using System.Windows.Threading;

namespace Daylit;

sealed class PushClient {
    /// What to connect to. The same target keeps the connection.
    public sealed record Target(Uri Url, string[] Entities, string? Daylight) {
        /// Records compare arrays by reference, so the entity lists are compared here.
        public bool Same(Target? o) => o != null && Url == o.Url && Daylight == o.Daylight && Entities.SequenceEqual(o.Entities);
    }

    /// Connected and subscribed: polling can slow down to PushRule.HealthyPollSeconds.
    public bool Healthy { get; private set; }
    /// After auth_invalid: the problem line for the panel, until the token or the config changes.
    public string? Problem { get; private set; }
    /// Healthy changed: the controller resets its poll timer.
    public event Action? HealthChanged;

    readonly Dispatcher ui;
    readonly Action tick;
    readonly Func<DateTime> lastTick;   // UTC; DateTime.MinValue before the first tick
    readonly Func<string?> token;
    Target? target;
    ClientWebSocket? ws;
    CancellationTokenSource? cts;
    SemaphoreSlim? sendGate;            // one send at a time per connection (ClientWebSocket allows only one)
    int conn;                           // bumped on every open and close: messages from an older connection do nothing
    int attempt, nextId = 1, subscribeId;
    bool stopped;                       // auth_invalid or no token: no retry until the token or the config changes
    bool awaitingPong;
    string? lastReason; DateTime? loggedAt;   // the once-then-every-10-minutes rule (HaErrorRule.ShouldLog)
    readonly PushTimer pending = new();
    readonly DispatcherTimer retry = new(), ping = new(), pong = new(), tickTimer = new(), network = new();

    public PushClient(Dispatcher ui, Action tick, Func<DateTime> lastTick, Func<string?> token) {
        this.ui = ui; this.tick = tick; this.lastTick = lastTick; this.token = token;
        retry.Tick += (_, _) => { retry.Stop(); Open(); };
        ping.Interval = TimeSpan.FromSeconds(PushRule.PingEvery);
        ping.Tick += (_, _) => SendPing();
        pong.Interval = TimeSpan.FromSeconds(PushRule.PongTimeout);
        pong.Tick += (_, _) => {
            pong.Stop();
            if (awaitingPong) { Lost("no pong", conn); return; }
            attempt = 0; lastReason = null; loggedAt = null;   // up for a minute: the next drop starts the backoff again
        };
        tickTimer.Tick += (_, _) => { tickTimer.Stop(); pending.Clear(); tick(); };
        // NetworkAddressChanged fires several times for one change: reconnect once, 2 s after the last.
        network.Interval = TimeSpan.FromSeconds(2);
        network.Tick += (_, _) => { network.Stop(); Reconnect("network change"); };
    }

    /// Opens, keeps or closes the socket. `force` reconnects even when nothing changed (a config reload resubscribes).
    public void Update(Target? t, bool force = false) {
        if (!force && (t == null ? target == null : t.Same(target))) return;
        var was = target;
        target = t;
        stopped = false; Problem = null;   // a new config gets a fresh try
        Close();
        attempt = 0; lastReason = null; loggedAt = null;
        if (t == null) { if (was != null) Log.Write(PushRule.OffLine); return; }
        Open();
    }

    /// A new token was saved: try again, also after auth_invalid.
    public void TokenChanged() {
        if (target == null) return;
        stopped = false; Problem = null;
        Close(); attempt = 0;
        Open();
    }

    /// Wake from sleep or a network change: the old connection may be dead without knowing it.
    public void Reconnect(string why) {
        if (target == null || stopped) return;
        Close(); attempt = 0;
        Open();
    }

    /// From NetworkChange.NetworkAddressChanged (on the UI thread).
    public void NetworkChanged() { network.Stop(); network.Start(); }

    void Open() {
        if (target is not { } t || stopped) return;
        if (token() is not { } secret) {
            // The REST tick already shows "No Home Assistant token"; AskToken calls TokenChanged().
            Close(); stopped = true;
            Log.Write("push: no token stored, waiting for one");
            return;
        }
        int c = ++conn;
        var socket = new ClientWebSocket();
        var source = new CancellationTokenSource();
        var gate = new SemaphoreSlim(1, 1);
        ws = socket; cts = source; sendGate = gate;
        _ = Run(socket, source.Token, gate, c, secret, t);
    }

    /// The receive loop, on the thread pool. auth_required is answered here, so the token never leaves this method.
    async Task Run(ClientWebSocket socket, CancellationToken stop, SemaphoreSlim gate, int c, string? secret, Target t) {
        string reason;
        try {
            await socket.ConnectAsync(t.Url, stop).ConfigureAwait(false);
            var buffer = new byte[16 * 1024];
            using var message = new MemoryStream();
            while (true) {
                var r = await socket.ReceiveAsync(new ArraySegment<byte>(buffer), stop).ConfigureAwait(false);
                if (r.MessageType == WebSocketMessageType.Close) { reason = "closed by Home Assistant"; break; }
                message.Write(buffer, 0, r.Count);
                if (!r.EndOfMessage) continue;
                var text = Encoding.UTF8.GetString(message.GetBuffer(), 0, (int)message.Length);
                message.SetLength(0);
                if (r.MessageType != WebSocketMessageType.Text) continue;
                var m = PushRule.Parse(text);
                if (m.Kind == PushKind.AuthRequired) {
                    if (secret is { } s) { secret = null; await Send(socket, gate, PushRule.AuthMessage(s), stop).ConfigureAwait(false); }
                    continue;
                }
                ui.BeginInvoke(() => Handle(m, c, t));
            }
        } catch (OperationCanceledException) when (stop.IsCancellationRequested) {
            return;   // closed on purpose
        } catch (Exception e) {
            // The type and code only: never a message that could quote the request.
            reason = e is WebSocketException we ? $"WebSocket {we.WebSocketErrorCode}" : e.GetType().Name;
        }
        ui.BeginInvoke(() => Lost(reason, c));
    }

    static async Task Send(ClientWebSocket socket, SemaphoreSlim gate, string text, CancellationToken stop) {
        var bytes = Encoding.UTF8.GetBytes(text);
        await gate.WaitAsync(stop).ConfigureAwait(false);
        try { await socket.SendAsync(new ArraySegment<byte>(bytes), WebSocketMessageType.Text, true, stop).ConfigureAwait(false); }
        finally { gate.Release(); }
    }

    /// A send from the UI thread; a failure closes and retries.
    async Task SendOrLose(string text, int c) {
        if (ws is not { } socket || cts is not { } source || sendGate is not { } gate || c != conn) return;
        try { await Send(socket, gate, text, source.Token); }
        catch (OperationCanceledException) { }
        catch (Exception e) { Lost(e is WebSocketException we ? $"WebSocket {we.WebSocketErrorCode}" : e.GetType().Name, c); }
    }

    void Handle(PushMessage m, int c, Target t) {
        if (c != conn) return;
        switch (m.Kind) {
            case PushKind.AuthOk:
                subscribeId = nextId++;
                _ = SendOrLose(PushRule.SubscribeMessage(subscribeId, t.Entities), c);
                break;
            case PushKind.AuthInvalid:
                Rejected(m.Reason ?? "");
                break;
            case PushKind.Result when m.Id == subscribeId:
                if (!m.Ok) { Lost("subscribe refused", c); break; }
                SetHealthy(true);
                Log.Write(PushRule.ConnectedLine(t.Entities.Length));
                ping.Start();
                break;
            case PushKind.Event:
                Request(m.Ids ?? new HashSet<string>(), t);
                break;
            case PushKind.Pong:
                awaitingPong = false;
                break;
        }
    }

    void SendPing() {
        if (ws == null) return;
        awaitingPong = true;
        _ = SendOrLose(PushRule.PingMessage(nextId++), conn);
        pong.Stop(); pong.Start();
    }

    void Request(IReadOnlySet<string> ids, Target t) {
        double now = Secs(DateTime.UtcNow);
        var last = lastTick();
        var d = PushRule.Decide(ids, t.Entities.ToHashSet(), t.Daylight, last == DateTime.MinValue ? null : (double?)Secs(last), now);
        if (!pending.Add(d, now) || pending.Due is not double due) return;
        tickTimer.Stop();
        tickTimer.Interval = TimeSpan.FromSeconds(Math.Max(0.01, due - now));
        tickTimer.Start();
    }

    void Lost(string reason, int c) {
        if (c != conn || target == null) return;
        Close();
        double delay = PushRule.RetryDelay(attempt++);
        var now = DateTime.UtcNow;
        if (HaErrorRule.ShouldLog(reason, lastReason, loggedAt is DateTime at ? (double?)Secs(at) : null, Secs(now))) {
            Log.Write(PushRule.LostLine(reason, delay));
            loggedAt = now;
        }
        lastReason = reason;
        retry.Interval = TimeSpan.FromSeconds(delay);
        retry.Start();
    }

    void Rejected(string why) {
        Close();
        stopped = true;
        Problem = PushRule.RejectedProblem;
        Log.Write(PushRule.RejectedLine(why));
        tick();   // shows the problem line
    }

    void Close() {
        conn++;
        awaitingPong = false;
        cts?.Cancel(); cts = null;   // not disposed: the receive loop may still hold its token
        try { ws?.Abort(); ws?.Dispose(); } catch { }
        ws = null; sendGate = null;
        retry.Stop(); ping.Stop(); pong.Stop(); tickTimer.Stop();
        pending.Clear();
        SetHealthy(false);
    }

    void SetHealthy(bool h) {
        if (Healthy == h) return;
        Healthy = h;
        HealthChanged?.Invoke();
    }

    static double Secs(DateTime t) => (t - DateTime.UnixEpoch).TotalSeconds;
}

## Experimental

### Push updates from Home Assistant

```json
"homeAssistant": {
  "url": "http://homeassistant.local:8123",
  "push": true
}
```

- **What it does.** Daylit keeps a WebSocket open to Home Assistant (`/api/websocket`, with the same
  token) and follows only the entities it reads: the blind, the lights, `autoSwitch`, the sun, the
  daylight sensor and each monitor's helpers. When one changes, the screens follow within about 2
  seconds instead of at the next check. The socket only says *when* to check; the check itself is the
  same as without it.
- **The daylight sensor** moves the screens at most once a minute on its own, because it can report
  every few seconds.
- **Checks still run** as a safety net: every 5 minutes while the connection is up (or your
  `timing.pollSeconds` / `batteryPollSeconds` if longer), and at the usual 30 seconds / 2 minutes while
  it is down.
- **When it is closed.** While the source is not Home Assistant, *Automatic* is off, the computer is
  paused on battery, or no external monitor is connected. Each change opens or closes it.
- **Reconnecting.** After a drop it tries again after 2, 5 and 15 seconds, then every minute. It also
  reconnects after sleep and when the network changes, and it sends a ping every minute: no answer
  within 10 seconds counts as a drop.
- **A rejected token** stops it until you save a new token (gear menu / tray menu → *Home Assistant
  token…*) or the config changes; the panel says so.
- **The log** shows `push: connected (N entities)`, `push: lost (<reason>), retrying in Ns` (once, then
  every 10 minutes while it keeps failing) and `push: off`. The token is never logged.
- **Behind a reverse proxy,** the proxy must pass WebSockets on `/api/websocket` (Home Assistant's own
  app needs that too).
- `--check-config` shows `"push": true` in its `homeAssistant` block.

To stop it, remove the key or set it to `false`.
```
